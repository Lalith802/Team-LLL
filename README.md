# Team-LLL - Student Team Members Management Application

This is a full-stack web application to manage student team members. Built as part of **FSD CT-2 Assessment** using the MERN stack.

---

## 🧰 Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js + Express.js
- **Database**: MongoDB
- **Image Upload**: Multer
- **HTTP Client**: Axios

---

## 📦 Features

- View the team name on the homepage
- Add new team members (with image upload)
- Display all team members in a grid layout
- View full details of each member
- Basic form validation and error handling
- Clean layout using basic CSS (no frameworks)

---

## 🔧 Installation Steps

1. **Clone the repository**
```bash
git clone https://github.com/Lalith802/Team-LLL
cd student-team-management

Start the backend

cd backend
npm install
node server.js

Start the frontend

cd student-team-management
npm install
npm start

```

To use your local MongoDB change the LocalHost Accordingly
